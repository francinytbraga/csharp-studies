# 🚀 Meus Estudos em C#

Bem-vindo(a) ao meu repositório de estudos e práticas em **C# (.NET)**! Este espaço é dedicado a registrar a minha evolução na programação, contendo exercícios de lógica, validação de dados e pequenas aplicações em console.

---

## 🛠️ O que você vai encontrar aqui?
* **Validações robustas:** Uso de `Regex`, `int.TryParse` e tratamento de entradas nulas.
* **Estruturas de controle:** Laços de repetição (`while`, `do-while`) e condicionais (`if`, `else`).
* **Manipulação de dados:** Uso de listas (`List<T>`) para armazenamento em memória.
